# Roblox and Luau Agent Skills

A collection of 19 agent skills for Roblox and Luau development, including
Studio workflows, networking, persistence, UI, monetization, performance,
typing, animations, Open Cloud, and game marketing artwork.

## Install everything

```bash
npx skills add flatbedj/roblox-skills
```

## Install one skill

```bash
npx skills add flatbedj/roblox-skills --skill roblox-core
```

Restart your agent after installation so it reloads the available skills.
